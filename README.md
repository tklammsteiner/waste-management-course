# Waste Management Lab Course (718837 UE Biogas)

Course website for the lab course **718837 UE Biogas** at the Department of Microbiology, Universität Innsbruck.

**Live site:** <https://tklammsteiner.github.io/waste-management-course/>

**Instructors:** Thomas Klammsteiner, PhD & Sebastian Hupfauf, PhD

## What's on the site

- **Slides**: Slide decks for specific course days

    - Day 4: [Pathogens & isolation](https://tklammsteiner.github.io/waste-management-course/assets/slides/day4/day4_pathogens_isolation.html){target="_blank" rel="noopener"}
    - Day 5: [Colony PCR](https://tklammsteiner.github.io/waste-management-course/assets/slides/day5/day5_colony_pcr.html){target="_blank" rel="noopener"}
    - Day 7: [Biomolecular characterisation](https://tklammsteiner.github.io/waste-management-course/assets/slides/day7/day7_biomolecular_characterisation.html){target="_blank" rel="noopener"}
    - Day 8: [Wrap-up](https://tklammsteiner.github.io/waste-management-course/assets/slides/day8/day8_wrap_up.html){target="_blank" rel="noopener"}
